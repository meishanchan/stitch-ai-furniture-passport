# Archive — 傢居數位履歷

可在 iPhone Safari 加入主畫面使用的家具網頁 App。

**網站：** https://meishanchan.github.io/stitch-ai-furniture-passport/

## 使用

1. Safari 開啟網站，點選分享 → 加入主畫面。
2. 開啟「打開為網頁 App」（如有此選項），點選加入。
3. 點任一家具進入數位履歷，左右滑動或使用底部導覽切換履歷、檢測與回購。

九件家具使用既有高解析透明圖片；收藏、展示檢測與示範預約保存在本機。照片只用於當次預覽，不會上傳。

## 展示範圍

本網站為互動展示，非 IKEA 官方服務。產品履歷、檢測、估價與預約均為示範資料，未連接真實 AI 檢測或回購服務。

HTML/CSS/JavaScript，無建置步驟與外部程式依賴。manifest 與 service worker 支援獨立視窗與首次載入後的離線快取。
