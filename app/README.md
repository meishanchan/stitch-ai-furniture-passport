# Archive 傢居數位履歷

手機 HTML 展示，保留提供的九件去背家具與四頁視覺。

## iPhone 操作

Safari 開啟發布網址，點分享 → 加入主畫面 → 開啟「打開為網頁 App」→ 加入。

九宮格點選任一家具，進入履歷；左右滑動或點底部「履歷／檢測／回購」切換；左上返回目錄。收藏、展示檢測與示範預約儲存於本機。檢測頁可依序拍攝或選取正面、側面與細節照片，三張齊全後進行示範分析；可個別重拍。照片只在當次頁面預覽，不會上傳，重新整理後需重新選取。

在家具履歷中點「索取螺絲與維護零件」→「下一步：查看零件圖」，可點選零件標記查看示意拆卸與安裝步驟；下方可播放或切換組裝步驟示意。零件位置、操作與播放內容皆為示範，請以產品原廠說明為準。

AI 與回購為示範流程，未連接真實檢測或 IKEA 服務。

## 本機

`npm start`（Python 3 提供 http://localhost:4173）；`npm test`（Node 內建測試，無套件依賴）。`dist/` 可直接部署至支援 HTTPS 的靜態網站。

原始檔案與素材資料夾保留不改。圖片為既有去背 PNG 原檔副本；App 圖示為幾何 SVG／PNG。manifest 與 service worker 提供獨立開啟與首次載入後的離線快取。

## 驗收範圍

已以瀏覽器手機尺寸檢查九件點選、三頁底部導覽與滑動、收藏、展示檢測、照片預覽、預約及重新載入保存；原生 iPhone Safari 與加入主畫面需在實機開啟發布網址驗收。

使用 impeccable 與 Sites。Gemini CLI 依指南嘗試後因 sandbox 的日誌寫入及 localhost bind 限制失敗，由 Codex 接手。還原時修正原稿「8 件」與實際 9 件不一致、沿用 MICKE 原稿數值，另修正預約變更未帶回已存選項。
